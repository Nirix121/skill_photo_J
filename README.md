# Сертификаты подлинности PALMIRA Jewels

Сайт для выставления, хранения и проверки сертификатов. Состоит из двух частей:

- **Лицевая сторона** — страница проверки `домен.com/verify/<адрес>`: показывает сертификат,
  даёт скачать PDF и открыть приложенный документ.
- **Внутренняя часть** — панель по секретному адресу `домен.com/<PANEL_PATH>` с входом
  по логину и паролю.

Все данные, файлы и логика живут на сервере. Наружу отдаётся только сам сертификат
по его адресу — база, список сертификатов и панель недоступны без входа.

Главная страница принимает полный проверочный код или ссылку с документа.
По одному номеру сертификата поиск невозможен: секретный адрес создаётся случайно.
Страницы самих сертификатов закрыты от поисковой индексации.

## Запуск

```bash
npm install
```

```bash
cp .env.example .env && npm run secret
```

Впишите в `.env` выданные `SESSION_SECRET` и `PANEL_PATH`, укажите `SITE_URL` — этот адрес
попадает в ссылки и в QR-код на сертификате. Затем заведите администратора:

```bash
npm run admin
```

```bash
npm start
```

В разработке удобнее `npm run dev` — сервер перезапускается сам при правке файлов.

## Как устроен адрес сертификата

При выставлении к номеру и папке дописывается 30 случайных цифр:

```
домен.com/verify/20104834edb424234092904284982...
                 └─номер─┘└┬┘└──── 30 цифр ────┘
                          папка
```

Цифры берутся криптостойким генератором и проверяются по базе, поэтому два сертификата
не могут получить одинаковый адрес. Номер и папка входят в адрес, поэтому после выпуска
они не меняются — адрес уже напечатан на документе.

Папок две: `ldb` и `edb`. Каждый сертификат получает свою папку на диске:

```
storage/edb/20104834edb4242.../
  certificate.pdf   — готовый PDF
  ring.jpg          — фото изделия
  document.pdf      — приложенный документ, если он есть
```

**Удаление освобождает адрес.** Панель удаляет и запись, и папку с файлами: страница
начинает отдавать 404, а этот же номер можно выставить заново — он получит новые цифры.

## Панель

Открывается по `SITE_URL/<PANEL_PATH>`. Секретный адрес — второй рубеж защиты помимо
логина и пароля, поэтому его не стоит публиковать и указывать в переписке.

Возможности:

- выставление сертификата со всеми полями макета (изделие, материал, камни);
- загрузка фото изделия и дополнительного PDF, который показывается под сертификатом;
- реестр всех сертификатов с поиском по номеру, изделию и адресу и фильтром по папке;
- правка и удаление выставленных сертификатов.

Вход защищён ограничением попыток: 10 за 15 минут с одного адреса.

## PDF

Публичная страница сертификата свёрстана на HTML. PDF создаётся напрямую библиотекой
PDFKit с теми же полями и оформлением: логотип, текст и QR-код рисуются векторно,
фотография декодируется и уменьшается через Sharp. Браузер для печати не запускается.
Шрифты PDF хранятся в `server/fonts/` вместе с лицензией; веб-страница использует
`public/fonts/`.

PDF собирается при первом скачивании и лежит в папке сертификата. После правки данных
файл сбрасывается и создаётся заново. При выпуске нового сертификата PDF готовится сразу.
Число одновременных генераций ограничено `PDF_CONCURRENCY` (по умолчанию 2).

## Структура

```
server/
  index.js            точка входа, маршруты верхнего уровня
  config.js           чтение .env и пути
  db.js               схема SQLite и запросы
  session.js          сессии администратора в той же базе
  auth.js             пароли (scrypt) и защита маршрутов
  routes/
    panel.js          вход и страница панели
    api.js            API панели: выставление, правка, удаление
    verify.js         публичная страница, PDF и файлы сертификата
  services/
    slug.js           генерация адреса
    storage.js        папки ldb и edb
    certificate.js    разбор и проверка формы
    render.js         модель шаблона, QR и сборка PDF
    pdf.js            прямая генерация PDFKit
  views/              шаблоны страниц, _sheet.ejs — сам лист сертификата
public/
  assets/             логотип, защитные линии
  fonts/              Nunito Sans для печати без интернета
  panel/              стили и логика панели
  verify/             стили публичной части
data/app.db           база: сертификаты, администраторы, сессии
storage/{ldb,edb}/    файлы сертификатов
```

## Публикация на текущем сервере

Приложение находится в `/home/server/certificate` и слушает только `127.0.0.1:3000`.
Для публичного адреса используется Cloudflare Tunnel. Боевой порядок действий,
команды для автозапуска, смены домена и удаления тестовых записей находятся в
`deploy/GO-LIVE.md`.

```bash
npm run check
npm run test:security
```

Копии базы, файлов сертификатов и исходного кода создаются ежедневно в `backups/`.
Хранятся последние 30 копий. Для защиты от потери сервера нужна вторая копия
на другом устройстве или в отдельном хранилище.

### Что учтено для публичного доступа

- Порт приложения доступен только локально; HTTPS заканчивается в Cloudflare.
- Заголовки безопасности включают CSP, HSTS, `X-Frame-Options` и `nosniff`.
- Вход ограничен 10 попытками за 15 минут, просмотр сертификата — 300 запросами,
  скачивание PDF — 60 запросами.
- Генерация PDF ограничена двумя одновременными заданиями и очередью.
- Сертификаты и вложения закрыты от поисковой индексации.
- При остановке сервер закрывает HTTP и базу данных.

## Шрифт

Макет рассчитан на Avenir Next: он есть в macOS, и там сертификат печатается именно им.
На сервере веб-страница использует Nunito Sans из `public/fonts/`, а PDF — статические
начертания Nunito Sans из `server/fonts/`. Интернет для отображения и печати не нужен.
